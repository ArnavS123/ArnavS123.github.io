ALU / SELECTED PROJECT

A CPU, from the ground up.

I built a custom 8-bit processor with a 16-bit instruction set in Digital Logic Sim, starting with gates and building up to registers, an ALU, memory, and a control unit.

I also created an assembler and NACAIS, a high-level language frontend, to connect programs to the processor.
